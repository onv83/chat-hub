# ChatHub — бэклог

Обсуждается и дополняется по ходу работы. Отмечайте `[x]` то, что закрыто.

## Контекст (что уже сделано)

- Electron-обёртка над веб-версиями: Mattermost, Telegram (через локальный прокси), MAX, Яндекс Чат/Телемост; persist-партиции сессий.
- Сборная вкладка «СБОРНАЯ»: слева список избранного, справа содержимое выбранного чата.
- Избранное — только ручное: тумблер ⭐/★ на вкладке мессенджера, меню «★ Избранное (N)», ✕ в сборной, список в настройках.
- Автосбор из папки «Astra» УДАЛЁН: кнопки «⭐⭐ Папка» нет, код коллекторов вырезан, ~47 автособранных чатов вычищено из конфига (2026-11-09).
- Раскладка сборной починена: список зафиксирован на 300 px со скроллом, webview полного размера (было: список разрастался, чат полосой сверху + белое поле).
- window.open внутри webview больше не создаёт отдельные окна Electron (Телемост): ссылки сервисов — в том же webview, OAuth-страницы — попапом, прочее — системный браузер.
- Сортировка избранного: (1) ручной приоритет ↑; (2) активность — открыл чат или пришли сообщения → наверх, удержание 7 дней; (3) позиция строки в списке мессенджера (TG/MAX сами сортируют по свежести); (4) ручной порядок.
- ⚙ Настройки — вкладка «⚙ Настройки» рядом с мессенджерами; в ней ползунок «Чатов в памяти» (2–20, по умолчанию 8): сколько избранных чатов держать загруженными для мгновенного открытия, применяется сразу.
- Фирменные иконки мессенджеров (favicon из их же сессий, data URL) в строках избранного и шапке вместо буквенного бейджа.
- Бейджи: в СТРОКЕ чата (красный, число новых; «@N» — упоминания), на ВКЛАДКЕ мессенджера (MM — @-упоминания всех личных, TG/MAX — счётчики) и на вкладке «★ Сборная» — общая сумма новых сообщений всех избранных чатов (красная, если есть @), видна не открывая вкладку. pollUnread каждые 5 с.
- Перетаскиваемая ширина списка сборной (разделитель, 220px–70% окна, сохраняется; двойной клик — 360px). Драг на Pointer Capture: события мыши над webview иначе уходят в гостевую страницу и «отпустить» драг нельзя.
- Вкладки мессенджеров предзагружаются при старте (панели через visibility, не display:none — webview в display:none не пересчитывает размер).
- Память: webview'ы в каждом чате избранного = процесс на чат; при 68 чатах было ~16,5 ГБ / 77 процессов. Теперь: предзагружены только топ-8 списка, остальные грузятся по клику, давно не открывавшиеся вытесняются (LRU; текущий чат и чаты с приоритетом ↑ не вытесняются). ~5 ГБ / 19 процессов.
- Загрузка всех webview идёт через последовательную очередь (dom-ready → следующий): одновременный старт многих вьюх MM уводит чаты на экран «Присоединиться к команде».
- Имена чатов берутся ТОЛЬКО из строк сайдбара/шапки этого чата (MM `span.SidebarChannelLinkLabel`, TG `.peer-title`, Телемост `.yamb-chat-bar .ui-cell_flex`); фолбэк на шапку/заголовок убран — он портил имена («Astra Team Chat»). MAX не переименовывается, Телемост — переименовывается (два разных чата Телемоста иначе оба зовутся «Яндекс Телемост»).
- Журнал решений window.open: `%APPDATA%\ChatHub\window-open.log` (для диагностики лишних окон Телемоста).
