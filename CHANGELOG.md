# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [0.3.0] — 2026-11-10

### Добавлено
- Настройка «У ★ Сборной всегда показывать счётчик новых»: счётчики вкладки «★ Сборная» остаются видимыми даже при выключенных общих счётчиках.
- Настройка «Показывать иконки на вкладках (сверху)»: фирменные иконки мессенджеров рядом с подписями в горизонтальной раскладке.
- Галочки в настройках: счётчики непрочитанных на вкладках и значок мессенджера в избранном — применяются сразу, без перезапуска.
- Аватарки чатов в избранном: захват из живых сессий мессенджеров (canvas/CORS/blob-пути), SVG-монограммы как запасной вариант, досбор прокруткой для виртуализированных списков Telegram.
- Логотип окна и приложения (SVG + build/icon.ico).
- Блок «О программе»: версия из package.json и краткая инструкция по работе.
- Вид «Панель слева»: перетаскиваемая ширина, узкий режим-рейл, футер с версией.

### Исправлено
- Telegram: пин мог показывать чужой канал — имя бралось из первой строки списка чатов; теперь имя из строки этого чата и только точных селекторов шапки.
- Telegram: закрепление чатов по @username (поиск строки по href), починка разбора id, мерж результатов поиска больше не затирает аватар.
- Telegram: фоновая индексация времени отключена по умолчанию — проходы печати деградировали список чатов webk.
- Телемост: закрепление чата (свежий адрес страницы + повтор через 1,5 с), личные чаты в guard'ах, задержка бейджей.
- MAX: личные чаты в guard'ах; стабильное скрытие списка чатов в пинах без правки grid-сетки.
- TG/MAX: пин-вьюхи уезжали за край при сужении окна — убраны фиксированные сдвиги (−202px / −77px), вместо них адаптивный CSS; конфиг мигрирует автоматически (columnCss v4).
- MAX: на основной вкладке после скрытия навигации оставалось пустое поле 77px — сдвиг теперь только при ширине ≥950px, при сужении сдвига нет.
- Светлая тема: невидимые при наведении иконки и кнопка «Убрать из избранного».
- Скрыто штатное меню Electron (File/Edit/View).

### Изменено
- MM-пины: только лента чата — скрыты верхняя полоса (продукты, поиск, помощь), шапка канала (кнопка Channel, участники, файлы) и полоса плагинов (focalboard, playbooks, todo). Правая панель тредов не скрывается: открытая с прошлой сессии закрывается при загрузке пина, новые треды открываются по «N ответов» как обычно.
- Белая тема Mattermost отменена: подмена темы удалена, MM использует свою тёмную тему; в настройках подпись «Светлая (мм не поддерживается)».
- Кнопка «Добавить мессенджер» убрана — набор мессенджеров фиксированный.
