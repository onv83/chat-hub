# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [0.4.1] — 2026-11-25

### Исправлено

- Кнопка «↗ Открыть во вкладке мессенджера» снова открывает конкретный чат. Причина была в гонке: очередь
  предзагрузки ставила базовый адрес сервиса, а ссылка на чат загружалась следом и перетиралась. Теперь
  глубокая ссылка встаёт в очередь приоритетно; для Telegram добавлен один контрольный повтор, если первая
  навигация пришлась на корень.
- Счётчик непрочитанного гаснет сразу после открытия чата в «Сборной», не дожидаясь перерисовки сервисной
  вкладки. Фоновый пересчёт подтверждает отметку прочтения; если сервис её не отправил, число возвращается.
- Ссылка в выгрузке Markdown больше не дублируется, если она уже есть в тексте сообщения.

### Тесты

- Мета-тест покрытия: каждый модуль `mcp-export/**`, каждый IPC-канал и каждый метод preload обязаны
  упоминаться в тестах — иначе прогон красный. Нашёл и закрыл пять непокрытых каналов и три метода.
- Шовный тест «сбор → манифест → мост → Markdown» с датами, `dayOnly` и `undated`.

## [0.4.0] — 2026-11-24

### Добавлено

- **Вкладка «MCP» в настройках**: папка выгрузки, ползунок глубины 1–30 дней, три карточки коннекторов
  (Mattermost, MAX, Яндекс Телемост), кнопка «Выгрузить проекты в MD», индикатор прогресса и отчёт.
- **Выгрузка избранных чатов в Markdown по проектам.** Поле «Комментарий 2 (проект для MCP)» в
  Настройках → Избранное: номера через запятую, несколько проектов дублируют чат в разные файлы.
  Файл `<проект>_<ДДММГГГГ>.md`: шапка с временем выгрузки и источниками, таблица «Время | Автор |
  Текст и ссылки | Message ID». Только текст, автор, время и ссылки — без фото, файлов, реакций и стикеров.
- **Локальный MCP-мост** (`mcp-export/`): ChatHub не держит токены и не ходит в MCP напрямую; мост
  запускает коннекторы по stdio, нормализует ответы и пишет файлы. Только read-only инструменты.
- **Реестр коннекторов** `%LOCALAPPDATA%\ChatHub\mcp\connectors.json`, кнопки «Установить/Обновить»,
  «Подключить существующий», «Проверить» (список инструментов и `whoami`, без чтения переписок).
- **Кнопка «Выгрузить список в MD»** в Настройках → Избранное: таблица избранного с сервисом,
  названием, ссылкой, комментарием и проектом.
- **Индикация потери сессии MAX**: маркер на вкладке вместо счётчиков, полоса предупреждения,
  однократное уведомление, пометка устаревших строк в избранном.
- **Журнал состояний сеансов** по всем сервисам в Настройках → Диагностика (последние переходы,
  время последней успешной проверки).
- `AGENTS.md` и `CHANGELOG-MESSENGERS.md` — правила для последующих правок модулей мессенджеров.

### Изменено

- Ответ MAX читается из вкладки ChatHub (webview), а не из отдельного окна с отладочным портом.
- Даты сообщений MAX определяются по разделителям ленты и мете сообщения.
- Пересборка файла за сегодняшнюю дату сохраняет предыдущую версию как `.prev.md`; при неполном
  составе в шапке появляются `partial: true` и `incomplete: [сервисы]`.
- Telegram: удалён неиспользуемый резервный разбор поиска.
- Счётчики непрочитанного: скрытые сервисные вкладки обновляются при фокусе, ручные названия
  избранного больше не перезаписываются авто-именованием.

### Исправлено

- Падение сохранения настроек при параллельном чтении `config.json` (транзиентный `EPERM`):
  запись повторяется для `EPERM`/`EACCES`/`EBUSY`.
- Флейк теста планировщика метаданных Mattermost (фиксированная пауза заменена ожиданием условия).
- В portable-сборку попадает каталог `mcp-export` (иначе кнопка выгрузки не работала бы в архиве).

## [0.3.5] — 2026-11-18

### Добавлено
- На вкладках всех мессенджеров появилась кнопка «↻ К исходной странице». В открытом избранном чате стрелка ↻ возвращает к сохранённому адресу чата.

### Исправлено
- Кнопка возврата ждёт завершения перехода и перезагружает страницу, если исходный адрес уже открыт.
- Telegram, MAX и Телемост показывают наблюдаемый счётчик непрочитанных на вкладке. Знак «+» означает, что это нижняя граница для виртуализированного списка.

### Изменено
- Electron обновлён до 45.3.4. Устаревшая диагностика пустой вкладки Телемоста удалена из обычного интерфейса.

## [0.3.4] — 2026-11-17

### Добавлено
- Значок ChatHub на панели задач показывает суммарное число непрочитанных сообщений только в избранных чатах — то же число, что на вкладке «★ Сборная».

### Исправлено
- Залипший системный счётчик на значке ChatHub очищается при отсутствии непрочитанных и не должен оставлять чужую цифру от встроенных веб-мессенджеров.

## [0.3.3] — 2026-11-16

### Исправлено
- Telegram: старое время вида `18:06` больше не становится временем из будущего и не поднимает старый чат выше свежих сообщений из других мессенджеров.
- У сообщений не за сегодняшний день снова показываются и время, и дата: например, `18:06 14.11`; для вчерашних — `15:03 вчера`.
- Фоновое обновление списка избранного больше не сбрасывает прокрутку наверх.
- Mattermost: строки без фотографии больше не расходуют лимит загрузки аватарок; аватарки поздних чатов в списке тоже подхватываются.

### Изменено
- Настройки разделены на вкладки. У настроек производительности и обновления Telegram есть понятное описание результата при включении и выключении.
- По умолчанию скрытые чаты из избранного бережнее используют ресурсы компьютера; счётчики непрочитанных продолжают обновляться.

## [0.3.1] — 2026-11-13

### Добавлено
- Portable-сборка Windows: архив можно распаковать в доступную для записи папку и запустить `ChatHub.exe`; настройки и сессии хранятся рядом с программой.

### Исправлено
- Обновление превью, автора, времени и счётчиков непрочитанных у избранных чатов Mattermost, Telegram, MAX и Телемоста.
- Сортировка избранного опирается на время последнего сообщения, поэтому старый чат не поднимается выше нового только из-за открытия или обновления счётчика.

## [0.3.0] — 2026-11-10

### Добавлено
- Настройка «У ★ Сборной всегда показывать счётчик новых»: счётчики вкладки «★ Сборная» остаются видимыми даже при выключенных общих счётчиках.
- Настройка «Показывать иконки на вкладках (сверху)»: фирменные иконки мессенджеров рядом с подписями в горизонтальной раскладке.
- Галочки в настройках: счётчики непрочитанных на вкладках и значок мессенджера в избранном — применяются сразу, без перезапуска.
- Аватарки чатов в избранном: захват из живых сессий мессенджеров (canvas/CORS/blob-пути), SVG-монограммы как запасной вариант, досбор прокруткой для виртуализированных списков Telegram.
- Логотип окна и приложения (SVG + build/icon.ico).
- Блок «О программе»: версия из package.json и краткая инструкция по работе.
- Вид «Панель слева»: перетаскиваемая ширина, узкий режим-рейл, футер с версией.

### Исправлено
- Telegram: пин мог показывать чужой канал — имя бралось из первой строки списка чатов; теперь имя из строки этого чата и только точных селекторов шапки.
- Telegram: закрепление чатов по @username (поиск строки по href), починка разбора id, мерж результатов поиска больше не затирает аватар.
- Telegram: фоновая индексация времени отключена по умолчанию — проходы печати деградировали список чатов webk.
- Телемост: закрепление чата (свежий адрес страницы + повтор через 1,5 с), личные чаты в guard'ах, задержка бейджей.
- MAX: личные чаты в guard'ах; стабильное скрытие списка чатов в пинах без правки grid-сетки.
- TG/MAX: пин-вьюхи уезжали за край при сужении окна — убраны фиксированные сдвиги (−202px / −77px), вместо них адаптивный CSS; конфиг мигрирует автоматически (columnCss v4).
- MAX: на основной вкладке после скрытия навигации оставалось пустое поле 77px — сдвиг теперь только при ширине ≥950px, при сужении сдвига нет.
- Светлая тема: невидимые при наведении иконки и кнопка «Убрать из избранного».
- Скрыто штатное меню Electron (File/Edit/View).

### Изменено
- MM-пины: только лента чата — скрыты верхняя полоса (продукты, поиск, помощь), шапка канала (кнопка Channel, участники, файлы) и полоса плагинов (focalboard, playbooks, todo). Правая панель тредов не скрывается: открытая с прошлой сессии закрывается при загрузке пина, новые треды открываются по «N ответов» как обычно.
- Белая тема Mattermost отменена: подмена темы удалена, MM использует свою тёмную тему; в настройках подпись «Светлая (мм не поддерживается)».
- Кнопка «Добавить мессенджер» убрана — набор мессенджеров фиксированный.
